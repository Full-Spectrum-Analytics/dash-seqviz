dash-seqviz

Interactive DNA, RNA & protein sequence visualization for Plotly Dash

Get Started GitHub

Live Demo

Installation

Python (PyPI)

pip install dash-seqviz

Conda

conda install -c conda-forge dash-seqviz

Quick Example

from dash import Dash, html
from dash_seqviz import SeqViz

app = Dash(__name__)

app.layout = html.Div([
    SeqViz(
        id="my-seqviz",
        name="pUC19",
        seq="TTGACGGCTAGCTCAGTCCTAGGTACAGTGCTAGC",
        viewer="both",
        annotations=[
            {"start": 0, "end": 22, "name": "Promoter", "direction": 1, "color": "#3b82f6"},
        ],
        enzymes=["PstI", "EcoRI"],
        style={"height": "500px", "width": "100%"},
    )
])

if __name__ == "__main__":
    app.run(debug=True)

Features

🧬

Circular & Linear Views

Toggle between circular plasmid maps, linear sequence views, or display both side by side.

🏷️

Annotations & Primers

Overlay named annotations, directional primers, and highlight regions on the sequence.

✂️

Restriction Enzymes

Visualize cut sites for 250+ NEB restriction enzymes or define custom enzymes.

🔍

Motif Search

Search for sequence motifs with configurable mismatch tolerance and highlight all matches.

🎨

Custom Colors

Color individual base pairs, annotations, translations, and highlights with full control.

⚡

Dash Callbacks

React to selection, search, and copy events via standard Dash callbacks.
