MLflow experiment tracking

SeqViz is a browser component, so it can't be pickled into MLflow like a model. But the seqviz library has a plain-JS viewer, so dash-seqviz can render a self-contained HTML file for any sequence + annotation configuration and log it as an artifact. MLflow renders .html artifacts inline (the same mechanism that makes Plotly figures interactive), so a logged seqviz.html shows the actual, interactive viewer right inside the run — themes and all.

Two surfaces, used together

SurfaceWhat it's forRenders the viewer?
Run + HTML artifact The visual, plus structured params / metrics / tags for comparison. ✅ inline in the Artifacts tab
Metrics & tags Sequence length, GC%, annotation coverage; a seq_sha256 tag groups variants of the same sequence. — drives the Compare view

Log a run

from dash_seqviz.integrations import mlflow as sv_mlflow

sv_mlflow.log_seqviz_run({
    "name": "pUC19",
    "seq": seq,
    "annotations": [
        {"start": 0, "end": 50, "name": "ori", "direction": 1},
        {"start": 80, "end": 400, "name": "AmpR", "direction": -1},
    ],
    "theme": "okabe-ito-light",
})

Compare variants of one sequence

Log several annotation / theme variants of the same sequence. They share a seq_sha256 tag (so they group), and each records comparable metrics — select them in the MLflow UI and click Compare. 

sv_mlflow.log_variants(
    "pUC19", seq,
    variants=[
        {"run_name": "bare",        "annotations": []},
        {"run_name": "annotated",   "annotations": annotations},
        {"run_name": "dark-theme",  "annotations": annotations, "theme": "dark"},
    ],
)

Install: the integration ships in the package under an optional extra — pip install dash-seqviz[mlflow]. Full API and a runnable demo: dash_seqviz/integrations/mlflow.py and examples/mlflow (see IMPLEMENTATION.md for wiring into a real experiment).
