MLflow

Log any sequence + annotation configuration as a self-contained HTML artifact. MLflow renders it inline, so the actual interactive viewer shows up right inside the run, themes and all.

SeqViz is a browser component, so it can't be pickled into MLflow like a model. Instead dash-seqviz renders the seqviz viewer to a standalone .html file and logs that, the same mechanism that keeps Plotly figures interactive in a run.

✓ Run + HTML artifact
The interactive viewer, inline in the Artifacts tab, alongside structured params, metrics, and tags for comparison.
Metrics & tags
Sequence length, GC%, annotation coverage. A seq_sha256 tag groups variants of one sequence and drives the Compare view.

Two calls

log_seqviz logs into the active run like mlflow.log_figure. log_variants fans one sequence out into comparable runs.

1

Log a run one viewer + its metrics

import mlflow
from dash_seqviz.integrations import mlflow as mlflow_seqviz

with mlflow.start_run():
    mlflow.log_params({"host": "E. coli"})
    mlflow_seqviz.log_seqviz({
        "name": "pUC19",
        "seq": seq,
        "annotations": [
            {"start": 0, "end": 50, "name": "ori", "direction": 1},
            {"start": 80, "end": 400, "name": "AmpR", "direction": -1},
        ],
        "theme": "okabe-ito-light",
    })
2

Compare variants one sequence, many runs

mlflow.set_experiment("plasmids")

mlflow_seqviz.log_variants(
    seq,
    variants=[
        {"run_name": "bare",       "annotations": []},
        {"run_name": "annotated",  "annotations": annotations},
        {"run_name": "dark-theme", "annotations": annotations,
                                   "theme": "dark"},
    ],
    name="pUC19",
)
